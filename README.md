# DESCRIPCIÓN
Ganadería WJ es una aplicación desarrollada en Python y Streamlit que permite registrar, consultar y administrar la información de los bovinos de una finca. 
Facilita el control del inventario, los pesos y las ventas, almacenando automáticamente los datos en Excel.

# PROBLEMATICA
En muchas fincas ganaderas, los registros se llevan manualmente, lo que puede ocasionar pérdida de información, datos duplicados y dificultades para controlar 
los animales y las ventas.

# OBJETIVO GENERAL
Desarrollar una aplicación web para gestionar la información de los bovinos de Ganadería WJ, facilitando el control del inventario, el seguimiento de sus pesos
y el registro de ventas mediante una interfaz sencilla y almacenamiento en Excel.

# OBJETIVOS ESPECIFICOS
Diseñar una interfaz clara que facilite el acceso de los usuarios y la consulta de información.

Implementar el registro de bovinos con identificación única, sexo, color y peso de entrada.

Registrar las ventas, incluyendo el peso de salida, el precio total y la actualización del estado del animal.

Almacenar automáticamente los registros en Excel para conservar la información y facilitar su consulta.

Mostrar indicadores y gráficos sobre el inventario, las ventas y el cambio de peso de los bovinos.

Validar los datos ingresados para evitar registros duplicados, campos incompletos y valores numéricos incorrectos.



# USUARIOS
Está dirigida a propietarios, administradores y encargados de fincas ganaderas que necesitan llevar un control organizado de sus animales.

# REQUERIMIENTOS
Registro e inicio de sesión de usuarios.

Registro de bovinos con identificación, sexo, color y peso.

Consulta y filtrado del inventario.

Registro de ventas y actualización del estado del animal.

Almacenamiento automático de información en Excel.

Visualización de estadísticas y gráficos.

# Funcionalidades
Inventario: consulta de bovinos registrados y disponibles.

Registro: ingreso de nuevos animales.

Ventas: registro del peso de salida y precio de venta.

Estadísticas: cantidad de animales, ventas totales y cambio de peso promedio.

Excel: almacenamiento y descarga de los registros.

# VALIDACIONES
Evitar identificaciones y usuarios duplicados.

Verificar que los campos obligatorios estén completos.

Validar que los pesos y precios sean mayores que cero.

Impedir la venta de un bovino que ya fue vendido.

Comprobar las credenciales de inicio de sesión.
